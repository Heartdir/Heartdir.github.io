# Zhizheng Sun — Research Homepage

Personal research homepage focused on intelligent railway perception, reliable industrial intelligence, and 3D hand understanding.

The site highlights selected publications in semantic segmentation, small-object detection, edge–cloud collaborative perception, domain generalization, remaining useful life prediction, and causal risk analysis.

## Local preview

Serve the repository with a local HTTP server and open `index.html` through that server. For example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Content

- `contents/home.md` — short introduction
- `contents/awards.md` — research directions
- `contents/experience.md` — selected publications
- `contents/publications.md` — contact links
- `contents/config.yml` — site metadata
